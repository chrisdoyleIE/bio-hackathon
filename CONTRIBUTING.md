# Contributing

Use a feature branch in this repository and open a pull request to main. No fork is needed for invited collaborators. All write collaborators can merge PRs without required approvals or checks. Accept your invitation and authenticate GitHub locally before pushing.

Before starting work, pull main and choose a distinct branch such as `yourname/habituation-model`. Avoid editing the same files concurrently without coordinating. Describe the change and how you validated it in the PR. Merge when ready and pull the updated main before your next task.

For Codex or Claude Code: ask the agent to work on a feature branch, validate the change, push the branch to this repository, and open a PR. Explicitly request merging when you want the agent to merge.

Keep secrets, virtual environments, and generated recordings out of Git. Preserve upstream attribution and licences. Cite research for biological mechanisms and distinguish simulated findings from tissue measurements.
